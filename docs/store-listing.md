  ```
  ‘시간표’는 AI 대시보드의 내 일정을 갤럭시워치에서 한눈에 보는 앱입니다.

  • 지금 시각에 걸린 일정이 자동으로 뜹니다.
  ```

## 스크린샷(Wear OS)

- 미리보기 화면을 폰으로 열어 캡처하면 됩니다: https://honest-family.github.io/ai-dashboard-app/watch.html
- 워치 스크린샷은 1:1 정사각형(예: 384×384 이상) 1장 이상이면 등록 가능합니다.

## 업로드 파일

- 최신 빌드 릴리스의 **ai-dashboard-watch.aab** 를 프로덕션에 업로드합니다.
- 다운로드: https://github.com/HONEST-FAMILY/ai-dashboard-app/releases/download/latest/ai-dashboard-watch.aab

## 콘솔 진행 순서

1. **개발자 등록**(대표님만 가능): play.google.com/console 접속 → 개발자 계정 등록(**최초 1회 $25**) → 본인 인증(신분증·전화). ※ 그냥 구글 로그인만으로는 안 되고, 이 ‘개발자 등록’이 반드시 필요합니다.
2. **앱 만들기**: 앱 이름=시간표 (AI 대시보드), 앱, 무료.
3. 스토어 등록정보(위 설명·스크린샷), 콘텐츠 등급 설문, 타겟층, **데이터 보안 양식**, **개인정보처리방침 URL** 입력.
4. **프로덕션**에 위 .aab 업로드 → 검토 제출(승인까지 보통 며칠).

## ⚠️ 로그인 연동 주의(중요)

- 플레이스토어에 올리면 **구글이 서명을 새로 합니다.** 그러면 지금 직접 설치해 쓰는 폰 앱(우리 서명)과 서명이 달라져, ‘폰에서 워치로 로그인 자동 전달’이 **작동하지 않습니다.**
- 그래서 스토어판 워치 앱에서도 로그인되도록, **워치에 뜨는 연결 코드를 폰 대시보드에 한 번 입력하는 방식(기기 연결 코드)** 을 추가해야 합니다. 이 작업은 개발로 처리합니다.
- 폰 앱까지 스토어로 올리면 서명이 같아져 자동 전달이 유지되지만, 폰 앱 심사·재설치가 필요해 권장하지 않습니다(폰은 지금처럼 직접 설치 유지).
